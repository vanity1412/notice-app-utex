# Cách lấy Moodle iCal URL

Trên Moodle/UTEx LMS thường làm như sau:

1. Vào Moodle UTEx.
2. Mở **Lịch / Calendar**.
3. Tìm mục **Export calendar / Xuất lịch / iCal**.
4. Chọn xuất tất cả sự kiện hoặc sự kiện khóa học.
5. Copy URL iCal.
6. Dán vào app.

Nếu Moodle chỉ tải file `.ics` thay vì cho URL, bản app này cần nâng cấp thêm chức năng import file `.ics` từ điện thoại.
