# PWA Frontend

Thu muc nay danh cho giao dien web/PWA cua sinh vien.

## Du kien chua

```text
src/
  app/ or pages/       # Man hinh chinh
  components/          # UI components
  features/            # Deadline, settings, notification setup
  lib/                 # Firebase client, helpers
public/
  manifest.webmanifest
  icons/
```

## Tinh nang

- Dang nhap sinh vien.
- Luu Moodle iCal URL.
- Hien thi lich deadline.
- Huong dan Add to Home Screen tren iOS.
- Dang ky Web Push subscription.
- Cai dat moc nhac deadline.
