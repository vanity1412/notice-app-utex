# Roadmap

## Giai doan 1: MVP

- Tao PWA hien thi deadline tu iCal URL.
- Dang nhap bang Firebase Auth.
- Luu iCal URL theo user.
- Backend sync thu cong khi user bam nut.
- Dang ky Web Push va gui notification test.

## Giai doan 2: Notification that su

- Scheduler sync Moodle moi 5-15 phut.
- Phat hien deadline moi/thay doi.
- Gui thong bao theo moc 1 ngay, 3 gio, 1 gio.
- Man hinh quan ly quyen thong bao va Add to Home Screen.

## Giai doan 3: Mo rong cho nhieu sinh vien

- Retry/backoff khi Moodle loi.
- Queue job de tranh sync dong loat qua nhieu user.
- An/mask token iCal tren UI va log.
- Dashboard co ban de theo doi so user, so job, so notification loi.
